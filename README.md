# Панель управления товарами (Admin Panel)

SPA-приложение для просмотра и управления каталогом товаров, разработанное в рамках тестового задания на стажировку. В качестве бэкенда используется Fake API (DummyJSON).

## Технологический стек

- Ядро: React 19, TypeScript, Vite
- Стейт-менеджмент: MobX (раздельные сторы: authStore, productsStore)
- Роутинг: React Router v7
- Формы и валидация: React Hook Form, Zod
- UI-библиотека: Ant Design v6
- Тестирование: Vitest

## Архитектурные решения

Сервер DummyJSON только делает вид, что сохраняет данные (POST/PUT/DELETE), но физически базу не меняет. Чтобы приложение работало правильно и данные пользователя не терялись при навигации, я добавил несколько решений:

- **Локальные патчи:** Все изменения, удаления и новые товары кэшируются в памяти MobX. Когда мы получаем свежий список с сервера, функция `applyPatches` накладывает наши правки поверх ответа. Благодаря этому удаленные товары не «воскресают» при переключении страниц или поиске.
- **Работа с пагинацией и сортировкой:** Пагинация работает на стороне сервера, при этом локально созданные товары аккуратно добавляются в самый конец списка. Также добавлена локальная пересортировка текущей страницы, чтобы товары с измененными ценами отображались в правильном порядке (так как сервер отдает их по старым ценам).
- **Синхронизация с URL:** Фильтры, сортировка и номер страницы сохраняются в адресной строке. Если уйти в карточку товара и вернуться обратно, таблица останется в том же состоянии.
- **Отмена лишних запросов:** Используется `AbortController` и `useDebounce`. Если быстро печатать в поиске или быстро переключать страницы, старые запросы отменяются, чтобы их ответы не перепутались.
- **Защита от потери данных:** Если начать заполнять форму и попытаться закрыть вкладку или обновить страницу (F5), браузер покажет предупреждение о несохраненных изменениях.

## Установка и запуск

Для работы требуется Node.js 18+.

```bash
npm install
npm run dev       # запуск локального dev-сервера (Vite)
npm run build     # сборка проекта (tsc -b && vite build)
npm run preview   # предпросмотр production-сборки
npm run test      # запуск юнит-тестов (Vitest)
npm run lint      # запуск линтера
